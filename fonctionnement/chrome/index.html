Comment ça marche

Retrouve une œuvre dans tes bibliothèques depuis ton iPhone ou dans Chrome.

Sur iPhoneSur Chrome

Vérifie depuis la fiche

  1. Choisis tes bibliothèques dans l’extension.
  2. Ouvre la fiche d’une œuvre sur un site compatible, comme Babelio ou SensCritique.
  3. Clique sur la pastille Biblib pour voir les exemplaires et ouvrir la notice.
Voir les bibliothèques compatibles

Comprends les résultats

Disponible

Regarde dans quelle bibliothèque se trouve l’exemplaire.

Emprunté

Consulte la date de retour si le catalogue l’indique. Ouvre ensuite la notice pour réserver.

Disponibilité à vérifier

Ouvre la notice pour vérifier l’état de l’exemplaire auprès de ta bibliothèque.
