# Site public de Biblib

Pages servies sur https://bublex.github.io/biblib-site/ : politique de confidentialité, mode d'emploi du raccourci téléphone. Les questions et signalements se font dans les [tickets](https://github.com/Bublex/biblib-site/issues).

Ces pages sont générées depuis le dépôt de Biblib (`node tools/site.mjs`) : ne les modifiez pas ici.
